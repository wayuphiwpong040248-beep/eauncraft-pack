STEP 1

ติดตั้งทีละขั้น

ทำครั้งเดียว ครั้งต่อไปแค่เปิดรันเชอร์แล้วกดเริ่มเกม มอดอัปเดตเองอัตโนมัติ

🛰️ ลง Radmin VPN

โหลดจาก radmin-vpn.com แล้วกด เข้าร่วมเครือข่าย (Join network)

🔑 ชื่อเครือข่ายและรหัสผ่าน ดูได้ในห้อง #🌐ip-เซิร์ฟ ใน Discord

⬇️ โหลดและติดตั้งรันเชอร์

โหลดตัวที่ตรงกับเกมของคุณจาก ด้านบน แล้วดับเบิลคลิกไฟล์ -Setup.exe

ถ้า Windows ขึ้นจอฟ้า “Windows protected your PC” ให้กด More info → Run anyway

📦 กดปุ่ม “ติดตั้ง”

รันเชอร์จะโหลดตัวเกม NeoForge มอด และ Java ให้ทั้งหมด ครั้งแรกประมาณ 1 GB รอจนแถบเต็ม

🔗 (เฉพาะ TLauncher) กด “ตั้ง Shortcut”

หน้าต่างดำจะเด้งขึ้นมา ทำตามที่บอกแล้วกด Enter ปิด — ตัว Premium ไม่ต้องทำข้อนี้

▶️ กด “เริ่มเกม”

TLauncher: เกมเปิดเองและรันเชอร์จะซ่อนตัว ปิดเกมแล้วรันเชอร์กลับมาเอง
Premium: Minecraft Launcher จะเปิดโปรไฟล์ “E'AunCraft Premium” ไว้ให้ → กด Play

Premium: ถ้า Minecraft Launcher เปิดค้างอยู่ ให้ปิดก่อนกดเริ่มเกม

HELP

แก้ปัญหาเบื้องต้น

เข้าเซิร์ฟไม่ได้ / Connection timed out
เช็ก 3 อย่าง: ① Radmin VPN เปิดและอยู่ในเครือข่ายของเซิร์ฟ ② แอดมินเปิดเซิร์ฟอยู่ (ไฟเขียวในรันเชอร์) ③ กดอัปเดตในรันเชอร์แล้ว ถ้ายังไม่ได้ แจ้งในห้อง #🛠️แจ้งปัญหา
ขึ้นว่ามอดไม่ตรง (Mod mismatch)
ปิดเกม เปิดรันเชอร์ใหม่ ถ้ามีปุ่ม อัปเดต ให้กด แล้วค่อยเข้าเกม
Windows / แอนตี้ไวรัส บล็อกไฟล์ติดตั้ง
กด More info → Run anyway ถ้าแอนตี้ไวรัสลบไฟล์ ให้เพิ่มโฟลเดอร์รันเชอร์เป็นข้อยกเว้น ไฟล์โหลดจาก GitHub ของเซิร์ฟโดยตรง
เกมแลค / FPS ต่ำ
ปิด Shader (กด O แล้วกด Shaders: OFF), ลด Render Distance เหลือ 8–10 และปิดโปรแกรมอื่น เซิร์ฟมี Sodium ช่วยเพิ่ม FPS อยู่แล้ว (Premium ปรับ RAM ได้ในโปรไฟล์ของ Minecraft Launcher)
ตายแล้วของหาย?
ไม่หาย! ของทั้งหมดอยู่ใน ศพ ตรงจุดที่ตาย กลับไปคลิกขวาที่ศพเพื่อเก็บของ ดูจุดตายได้จากแผนที่ JourneyMap
